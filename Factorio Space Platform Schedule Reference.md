# Factorio Space Platform Schedule Reference

Source: Owner-provided Factorio screenshots and accompanying direction in the Wayfinder conversation
Imported: 2026-10-07

## Source Snapshot

The owner supplied two screenshots as inspiration for Galaxia's route queue. They explicitly said not to copy Factorio's system one-to-one.

The first screenshot shows a vehicle or platform named TAXI, an automatic-mode control and a vertically ordered schedule. Destination rows include Fulgora, Vulcanus, Nauvis, Gleba, Muluna and Cerys. Each destination has its own nested wait-condition rows and an Add wait condition control. Destination rows also show an Unload checkbox. The panel includes an Add station control, per-row removal controls and a highlighted current destination.

The second screenshot shows the Add wait condition menu. Visible choices are All requests satisfied, Any request not satisfied, Any request zero, Circuit condition, Damage taken, Inactivity, Item count, Passenger not present, Passenger present, Request not satisfied, Request satisfied and Time passed.

These screenshots demonstrate the grouping and visible controls. They do not establish approval of every displayed condition or its behavior for Galaxia.
