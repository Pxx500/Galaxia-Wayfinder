# Collect Data Processor Topology Feedback

## Question

What constraints and preferences do the other Galaxia developers provide for choosing between an expandable modular Data Processor multiblock, a network-pooled set of smaller machines, or another physical processing topology?

## External Dependency

The required input is the responsible developers' feedback, not another code search. The 2026-09-12 audit found no implemented gameplay Data Processor topology in the inspected registry owners. The debug data generator does not answer this design choice. This task remains blocked on that coordination and is not an immediately answerable grilling question.

## Completion Evidence

- Record the viable alternatives and the gameplay reason for each.
- Identify how each alternative owns processor hardware, scaling, EU use, job configuration, and player-facing status.
- Capture any technical or content constraint that rules an alternative in or out.
