# Define Alpha Research and Production Floor

## Question

Which research, satellite-data, destination-dependent production, and other non-extraction gameplay chains must appear somewhere in Galaxia Alpha, beyond the already accepted acquisition and processing contracts?

## Established Decisions

- [[Define Alpha Technology Knowledge Contract]] owns consumed Technology Blueprints, team knowledge, production checks, and catalog behavior. Those rules are resolved, not blocked by the remaining proposal review.
- [[Define Prospecting Data Processing]] owns the accepted origin-bound processing and return pipeline. [[Define Data Processor Machine Topology]] owns the resolved expandable-multiblock design.
- Define Non-Material Tier Gate Role excludes mandatory bosses and dungeons from progression.
- Define First Physical Station Contract retains orbital-production candidates and a working lunar Space-Grade Alloy direction. These do not yet prove the complete mandatory production floor.
- Richer planetary experiments are later work, not a prerequisite for the accepted Alpha blueprint mechanism.

## Production Machinery Baseline

The owner reaffirmed the existing project direction on 2026-09-17: Galaxia primarily uses GregTech machines and their normal production capabilities. A custom machine is an explicit exception justified by a process requirement that existing machinery cannot satisfy, not a default choice for each new chain.

Apply this baseline to orbital production and other Galaxia processing chains. Investigate existing capabilities before proposing a custom machine. Do not ask the owner to choose between GT and custom machinery again without identifying the concrete unmet requirement.

## Accepted Orbital Production Minimum

On 2026-09-16 the owner accepted one complete orbital production chain as the current Alpha minimum. It must run from obtainable feedstock to a product with a concrete use. This is a delivery minimum, not a cap on orbital content. More orbital production chains are planned for later expansion.

The silicon-germanium crystal and specialty optical-fiber candidates remain available. This decision does not choose between them, reject the other candidate, or require both for Alpha. [[Define First Physical Station Contract]] owns their environmental rationale and the unresolved role that makes the first Station necessary for progression.

## Remaining Decisions

- Which additional destination-dependent production chains are essential to Alpha rather than optional depth?
- Which reviewed proposals supply those chains and satisfy a complete input, activity, output, and progression continuation?
- Which orbital candidate supplies the accepted first complete chain, including obtainable feedstock and a useful output. Machinery follows the production baseline above unless a concrete unmet requirement justifies an explicit exception.
- Which concrete technologies and recipe groups populate the accepted knowledge mechanism? Material and transport placement is developed in Map Alpha Tier Routes.

[[Review Crater Nodes Proposal]] resolves the revised crater gameplay chain. Concrete recipes, balance and integration remain execution work. The imported-proposal review is also resolved, so the remaining production-floor discussion is unblocked. None of this reopens the accepted technology acquisition contract.

## Consolidation

On 2026-09-12 the settled technology mechanism was extracted into its own resolved decision. This ticket retains its original broader content-floor question and is not marked complete merely because the blueprint mechanism is settled.
