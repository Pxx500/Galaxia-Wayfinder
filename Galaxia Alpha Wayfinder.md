# Galaxia Alpha Wayfinder

Return to [[00 - Galaxia Alpha Command Center]].

## Destination

Clarify the durable gameplay requirements needed for a playable Galaxia Alpha with closed progression routes and automatable infrastructure. A resolved decision describes accepted intent, not an implemented or verified feature.

## Working Rules

Use the area hubs to find current decisions and open questions. Preserve provisional tuning as provisional. Group independent questions in a discussion round and do not re-ask consequences already settled by an accepted rule. Code-dependent uncertainty requires current evidence when implementation begins.

Work independent questions across areas in grouped rounds, then continue to the next unblocked decision. Check existing decisions before asking again. Create a ticket when an open question is precise enough to resolve. Pause for a required answer, evidence or authorization. Do not reopen deferred systems or invent questions to fill a round.
