# Galaxia-Wayfinder

The Obsidian planning vault for Galaxia. It contains planning maps, decision tickets, research, source material, and the project's domain glossary.

## Required skill

To use this repository correctly, use the **Wayfinder** skill from [mattpocock/skills](https://github.com/mattpocock/skills). Install the skill in your coding agent and invoke it when working through planning maps and decision tickets.

Wayfinder guides planning by resolving decisions before implementation. This repository keeps its maps and tickets in Markdown files within the vault. Follow the local workflow in [Galaxia Wayfinder Guide](Galaxia%20Wayfinder%20Guide.md).

## Getting started

1. Clone this repository and open the folder as a vault in Obsidian.
2. Read [Agent Briefing](Agent%20Briefing.md) for task-specific guidance.
3. Start from [Galaxia Alpha Command Center](00%20-%20Galaxia%20Alpha%20Command%20Center.md) and follow the links to the relevant map, area, and decision ticket.
4. Use [CONTEXT](CONTEXT.md) for the project's domain terminology.

Imported source material is not accepted design until it has been reviewed through the Wayfinder workflow. Accepted decisions live in their owning tickets.

Local Obsidian settings and trash are excluded from version control.
